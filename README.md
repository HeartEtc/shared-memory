## 10 条方法论（贯穿全程）

1. 改代码 → 重跑测试 → 才 commit
2. 测"拒绝"必须同时断言"状态没变"
3. 边界值优先（0 / 负数 / 刚好相等）
4. `equals`/`hashCode` 只用身份字段，不用状态字段
5. `double` 不存钱，`boolean` 不表达多状态
6. 一个 `if` 只表达一件事，`!(A||B)` 一律拆开
7. 先查权限/校验，再碰数据
8. 消息必须与事实一致
9. README 必须与仓库一致（靠干净克隆验证）
10. 项目收口 = 推 GitHub + 干净克隆可复现
